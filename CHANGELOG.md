# SSLNexus Public Changelog

## 1.0.6 — 28 September 2026

### New
- Added Dependency & Impact views to help administrators understand known relationships between certificates, certificate authorities, deployment targets, hosts, applications and trust stores before making changes.
- Added Trust Store Management for organisation-scoped public root and intermediate CA bundles, discovery, drift visibility and controlled provisioning across supported Linux and Windows targets.
- Added certificate issuance-history charts with 30, 90 and 365-day views and links back to detailed activity records.
- Added a dedicated About page showing the installed release, build information, system information, effective licence, capacity usage, expiry and customer support identifiers.
- Added global dashboard search with direct navigation to relevant sections.
- Improved domain discovery with broader source coverage and clearer source diagnostics.
- Added clearer Client Area account linking with explicit recipient consent and non-billing Licence User access for linked accounts.

### Security and privacy
- Vendor Portal certificate requests now generate private keys locally in the user's browser. The private key is not generated by or returned from the SSLNexus Client Server.
- Added a published Private Key Policy describing the SSLNexus key-custody model.
- Replaced emailed temporary team passwords with single-use password-setup links.
- Added source-aware login throttling and clearer repeated-login / possible brute-force events in Activity & Audit.
- Improved access-log differentiation between Client Server administrators and Vendor Portal users.
- Hardened self-hosted GitLab configuration against unsafe local and link-local destinations by default.

### Reporting and usability
- Reworked PDF reports with SSLNexus branding, improved table wrapping, continuation-page headers and consistent pagination.
- Renamed the Reports export action from “Branded PDF” to “PDF”.
- Improved dark-mode readability throughout Dependency & Impact.
- Added consistent password show/hide controls for user-password fields while keeping API tokens, keys and application secrets masked.
- Improved action feedback and navigation consistency across administration surfaces.

### Reliability and operations
- Improved discovery diagnostics and recovery behavior around partial source failures.
- Improved certificate-capacity reconciliation and retained authoritative licence behavior across finite tiers.
- Preserved existing 1.0.x installation and upgrade paths.

### Upgrade
- Upgrades from SSLNexus 1.0.5 use the normal native package upgrade process. Review the Upgrade Guide and keep a current backup before changing production systems.

## 1.0.5 — 25 September 2026
- Expanded multi-tenant MSP management and organisation isolation.
- Added and refined first-party network-appliance certificate workflows, including F5 BIG-IP, VMware vCenter and PAN-OS.
- Expanded Internal PKI capabilities and access controls.
- Improved operations health, notification routing, backup/restore workflows and certificate-capacity handling.
- Added native DEB and RPM release distribution, immutable versioned package records and version-aware upgrade notifications.

## 1.0.4 — 19 September 2026
- Added verified parent-domain discovery with Certificate Transparency fallback.
- Added provider-neutral adoption of discovered certificates into managed deployment targets.
- Added certificate destinations for HashiCorp Vault, AWS Secrets Manager and Azure Key Vault.
- Added named Entra ID, Okta, Google Workspace and generic OIDC sign-in integrations.

## 1.0.0
- Initial public SSLNexus release with the permanent Free tier, paid licensing, Vendor Portal, certificate lifecycle automation and native Linux packaging.
